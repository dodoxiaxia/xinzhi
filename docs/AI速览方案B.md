# AI速览运行说明（v7，2026-09-30）

AI速览帮助读者浏览公开摘要，属于模型生成、未经人工核对的内容。它与 `editorial/source_checked_drafts.json` 的摘要核对导读分开保存和展示，不提供微信群文案，不标医生终审。

## 当前流程

在刷新候选后先演习：

```sh
python3 scripts/generate_quicklooks.py --limit 3 --lookup-limit 12
```

小批量真实调用：

```sh
python3 scripts/generate_quicklooks.py --call-model --limit 3 --lookup-limit 12
```

默认最多3次模型调用、12次Europe PMC摘要检索。参数硬上限为20次模型、40次检索；这只是程序上限，不是自动任务的默认预算。先逐项核对来源身份、引句、数字、标签、失败记录，再决定是否扩大。使用本机已配置的GLM-5.3-Flash，不自动切换模型或循环重试。

候选与文献库合并后按DOI/PMID去重，只处理近45天的核心心血管、AI医疗题录，跳过已核对导读和已有速览。优先使用完整、非片段的PubMed原摘要；不足时按DOI/PMID查询Europe PMC并核对返回身份。摘要缺失的条目不调用模型。

每条要点附原摘要逐字引句，数字必须有摘要依据。这些机械校验不能代替医学审查。API、模型格式或证据校验失败会立即停止，整批保留原 `data/quicklooks.json`，私有诊断只记录固定错误类别；不输出密钥或响应正文到公开日志。

成功写入后，按当前交付状态在隔离副本使用最新 `scripts/build_public.py` 构建并核验公开清单。当前生产包含 Worker 的六文件与原五文件发布范围尚待同步，保留现有站点，不能按历史五文件流程上传或删除 Worker；待范围明确后遵循现有 Cloudflare 流程。打包完成不等于公网发布。
