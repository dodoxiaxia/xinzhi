## 如何使用

GitHub是后台文献来源。维护流程先拉取索引，再按DOI、题名、期刊或常见中文医学关键词选择文章；只取需要的一篇PDF。索引和PDF保存在本机 `.local/github-library/`，不会合并进公开文献库，也不生成全文医学评价。公开网站继续显示经核对的原创导读、公开摘要与期刊原文入口，现有1,219条公开题录范围保持不变。

本机编辑台增加“GitHub文献库”只读检索入口，沿用现有登录门禁。未登录不能读私有索引，网页不提供批量下载或自动发布按钮。Cloudflare上的公开五文件网站尚无云端私有文献后台，本机接入成功不能称为云端后台已授权。

## 同步和单篇取用

```sh
python3 scripts/github_library.py sync
python3 scripts/github_library.py search 房颤 --limit 20
python3 scripts/github_library.py search 10.1038/s41591-025-03517-w
python3 scripts/github_library.py fetch PAPER_ID
```

使用现有gh登录，不把GitHub令牌写入源码、浏览器或公开包。同步固定同一GitHub提交读取索引并保存指纹；失败保留上个有效快照。取PDF固定快照提交和索引中的相对路径，校验PDF文件头、大小、Git blob及合法的索引SHA-256，记录来源提交和文件哈希。索引哈希缺失时只证明固定提交的文件一致，收据不会标成索引SHA已核验；非空异常哈希的条目只可检索，拒绝取用，等待上游修正。SHA校验通过只证明文件与索引一致，使用文献前还要核验题名、DOI与实际全文内容。

每日任务先同步私有索引，用于查重、选文和查找周五精读全文；读取失败可以沿用旧快照并明确其日期，不凭空宣称已跟上仓库最新版本。仅维护既有每日任务，不增加第二个日更调度，也不修改上游文献库的定时任务。

## 未来云端后台

若要让云端后台脱离Mac读取私有库，需另行配置只针对 `dodoxiaxia/AI-`、内容只读的GitHub App或细粒度令牌，并将凭据放在服务端受保护配置中。用户授权后台使用资料不等于将仓库或PDF公开，也不等于已创建这项云端凭据。GitHub的[细粒度令牌说明](https://docs.github.com/en/authentication/keeping-your-account-and-data-secure/managing-your-personal-access-tokens)支持仅选择指定仓库；[部署凭据说明](https://docs.github.com/en/enterprise-cloud%40latest/authentication/connecting-to-github-with-ssh/managing-deploy-keys)说明GitHub App可限定内容只读权限。本轮不创建新凭据、扩大账号权限或改动Cloudflare设置。
