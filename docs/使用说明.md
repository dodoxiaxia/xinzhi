# 心知使用说明（v7）

公开网址：https://learn.dryz.info/ 。实际已上线版本以 `docs/当前交付状态.md` 为准。

1. **先读精选。** “每日精选”按精选日期归档，包含中文导读、证据边界、共读问题和原文入口。点击“阅读导读与摘要”打开详情；需要分享时复制群文案，自行粘贴到学习群。
2. **按刊查新。** 在“文献雷达”选期刊，点“关注期刊”，以后用“我的期刊”查看关注内容。也可选择“有公开摘要”“已核对导读”或“AI速览”。连续中文如“房颤消融”可直接搜索；“近7天”按当前北京时间计算。
3. **查旧文、做晨会准备。** “文献库”提供已有题录检索和公开摘要入口。下载功能启用后，点击“下载 PDF”，输入全文口令即可保存已收录全文；没有可用全文时仍可访问“官网原文”。点“晨会单”收集文章并导出材料。关注期刊和晨会单仅保存在当前浏览器，暂不跨设备同步。下载配置见 [PDF下载接入](PDF下载接入.md)。
4. **读周报与内部共读。** “本周精读”没有新一期时明确显示未发布，旧示范不代表本周完成。内部共读文档目前仅授权dryz@dryz.info，需要该Google账号登录；增加同事须逐个授权，保持受限共享。

阅读层级要区分：原摘要是来源内容；AI速览未经人工核对；中文精选已按标注范围做摘要核对，仍未经医生终审；全文精读须明确取得并审查全文。自动研究类型与标签用于导航，未知信息保留待核验。

## 筛选与切换浏览（v14.3.1）

- 左侧各模块单选，同组点击新选项替换原选项，再次点击已选项保持选择；不同模块的条件需同时满足。例如选 Circulation 再选 RCT，会显示 Circulation 中的 RCT。
- 已有其他左侧条件时，选项旁会出现“只看”。点击“只看 RCT”会移除信源分组、期刊和主题等其他左侧条件，只保留 RCT；顶部领域、时间、关键词、可读内容及“我的期刊”条件保留。
- 出版方名称用于筛选该出版方，右侧箭头只展开或收起旗下期刊。顶部期刊下拉框与左侧期刊共享选择；换到另一出版方的期刊会同步更新所属出版方。
- 结果上方显示“当前筛选 · 同时满足”。点一个条件的 × 只移除该维度；期刊与出版方属于同一维度，清除期刊不会暗中保留出版方。“清空左侧筛选”保留顶部条件；“重置所有条件”恢复默认范围并清除关键词。
- 选项数量按其他条件计算，表示替换本组选项后的匹配篇数。零匹配选项仍可用“只看”切换浏览。组合无结果时，页面提供保留其中一项的实际篇数和按钮，不自动放宽条件。

每日08:00任务使用本机查新、GLM初稿、主代理复核及现有Cloudflare发布流程。网站持续托管；更新执行依赖本机、网络与有效登录，未来无人值守发布尚未证实。失败时保留上期及真实日期。
