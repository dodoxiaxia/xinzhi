# t19：404、爬虫入口与分享卡片

## 根因与范围

- Pages 在没有顶层 `404.html` 时把未匹配的路径当成 SPA 路由，回退到首页。现有高级模式 Worker 直接返回 `env.ASSETS.fetch(request)`，继续由 Pages 处理静态资源与 404，无需改 Worker。[Pages 路由及回退规则](https://developers.cloudflare.com/pages/configuration/serving-pages/#not-found-behavior) · [高级模式](https://developers.cloudflare.com/pages/functions/advanced-mode/) · [ASSETS 绑定](https://developers.cloudflare.com/pages/functions/api-reference/#envassetsfetch)
- `robots.txt` 允许抓取公开页面，只禁止抓取 `/api/`，并公布站点地图地址；robots 规则不是访问控制。站点地图只列首页。RSS 已通过首页的 RSS 链接公布；精读示范是单篇文献的嵌入片段，不是独立落地页。带查询参数的链接、精读分片和私有路径也不列入。日期取构建清单的 UTC 日期，格式遵循 [Sitemaps 协议](https://www.sitemaps.org/protocol.html)。
- 首页分享卡片的标题和描述为静态 HTML。现有图标为 192 × 192 px，小于 200 × 200 px，部分客户端可能不显示图；不新增图片。精读示范文件是阅读面板用的 HTML 片段，没有 `<head>`，不加分享标签。
- `robots.txt` 与 `sitemap.xml` 缓存 300 秒；直接访问 404 页面时要求重新验证。对原始未知 URL 不加通配缓存规则，以免影响首页、现有静态文件或 API。

## 客户端路由审计

| 源码 | 地址栏变化 |
| --- | --- |
| `src/app/09-weekly.js` | `deepReaderUrl()` 只增删 `read` 查询参数，保留当前路径和片段。 |
| `src/app/04-filters.js` | `pushOverlay()` 复用当前 URL；`syncUrl()` 只更新查询参数。 |
| `src/app/10-browse-events.js` | 栏目切换压入当前 URL，随后同步筛选参数，不添加路径。 |
| `src/app/06b-reading-mode.js`、`src/app/01-state-helpers.js` | 只更新 `paper` 或移除 `list` 查询参数。 |

首页和旧 `/index.html` 链接仍由 Pages 处理；所有已注册 API 路由继续走原处理器。未注册的路径（含未注册的 `/api/…` 路径）才进入静态 404 回退。

## 发布后只读核验

```sh
base=https://learn.dryz.info
curl -sSI "$base/nonexistent"                    # 404、text/html；确认未长期缓存
curl -sSI "$base/robots.txt"                     # 200、text/plain
curl -sSI "$base/sitemap.xml"                    # 200、application/xml
curl -sSI "$base/"                              # 200、text/html
curl -sSIL "$base/index.html?mode=weekly"        # 保持原 Pages 跳转行为，最终 200
curl -sS -i -H 'Accept: application/json' "$base/api/muse/protocol" # GET；200、JSON、schemaVersion: 1
curl -fsS "$base/robots.txt"
curl -fsS "$base/sitemap.xml"
curl -fsS "$base/" | grep -E 'property="og:|name="twitter:card"'
```

部署前的离线结果不等同于公网验证。生产 CDN 的缓存行为和微信/Slack 的卡片渲染需部署后再核验。
