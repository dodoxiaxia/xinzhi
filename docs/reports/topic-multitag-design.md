## 匹配真值表

A、B 代表任意不同标签。下表先假定其他已启用的筛选均满足。

| 所选主题 | 论文标签 | 任一（OR） | 同时包含（AND） |
| --- | --- | --- | --- |
| 无 | 无、A、B 或 A+B | 是 | 是 |
| A | 无或只有 B | 否 | 否 |
| A | A 或 A+B | 是 | 是 |
| A+B | 无 | 否 | 否 |
| A+B | 只有 A 或只有 B | 是 | 否 |
| A+B | A+B，可再有其他标签 | 是 | 是 |
| 未分类 | 无可用主题标签 | 是 | 开关禁用 |
| 未分类 | 至少一个可用主题标签 | 否 | 开关禁用 |

最终命中要求每个启用的筛选维度均满足。期刊档与指定期刊/出版方沿用现有来源选择规则，选专题不会改来源，选来源不会清主题。单选时显示「单选时无区别」。选择未分类会清掉具体标签，选择具体标签会退出未分类。

| 其他条件 | 主题匹配，其余条件均匹配 | 主题匹配，仅该条件未匹配 | 主题不匹配，其余均匹配 |
| --- | --- | --- | --- |
| 期刊档、指定期刊或出版方 | 是 | 否 | 否 |
| 专科来源 | 是 | 否 | 否 |
| 研究设计 | 是 | 否 | 否 |
| 关键词 | 是 | 否 | 否 |
| 栏目领域和时间窗口 | 是 | 否 | 否 |
| 文献库全文状态 | 是 | 否 | 否 |

精确 DOI 直达沿用专用查重视图。近7天榜以榜单的七日窗口与榜首总数为准，每日精选计入其当前日期选择与原有回退规则。

## 点击后的篇数

从同栏目中通过其他条件的论文开始，按每个候选动作模拟添加或移除标签，使用同一个匹配函数计数。已选标签显示移除后的篇数；「全部」显示清掉主题后可见的篇数；「未分类」未选时显示无标签篇数，已选时再次点击会取消并显示取消后的篇数。合法 0 保持灰显并可点击。切换匹配方式也可预看篇数；未分类时禁用该开关。期刊档主按钮按点击后的来源范围计算，保留主题条件。#206 的期刊清单行和其他既有筛选弹层各自的计数逻辑在本单范围外。

## 分组提议

| 组 | 归属 | 理由 |
| --- | --- | --- |
| 临床亚专科 | #房颤/电生理、#心衰/心肌、#卒中/抗凝、#高血压/血管、#冠脉介入、#结构性心脏病、#先心病、#预防/血脂 | 按疾病、临床方向或专科干预查找 |
| 检查与手段 | #心电、#影像 | 两种可横跨临床亚专科的检查 |
| AI 与数字医学 | #AI-ECG、#大模型/NLP、#AI-RCT证据、#穿戴/远程监测 | 按模型、数字工具或数字医学证据查找 |
| 其他 | 数据或分享链接中出现的额外主题 | 保留当前词表之外的可选项 |

分段显示组名和已选数。窄屏允许标签换行并限制面板高度，列表与结果总数位于面板之后。卡片最多显示三个主题徽标，额外显示「+n」；徽标沿用主题选项的切换行为。阅读面板由 t5 处理。

## URL 与预设兼容

| 输入 | 恢复状态 | 再分享 |
| --- | --- | --- |
| `tag=A` | 单标签，任一 | `tag=A` |
| `tags=A,B` 或坏值 `tagmode=xyz` | 多标签，任一 | `tags=A,B` |
| `tags=A,B&tagmode=all` | 多标签，同时包含 | 保留 `tagmode=all` |
| `tag=A&tagmode=all` | 单标签，同时包含，结果等同任一 | 保留 `tagmode=all` |
| `tagmode=all` | 先设匹配方式，再选标签 | 保留 `tagmode=all` |
| `tags=uncategorized&tagmode=all` | 未分类，开关禁用 | 只写 `tags=uncategorized` |
| 旧预设，无 `tagMode` | 任一 | 默认模式省略 |
| 新预设，`tagMode: all` | 恢复同时包含 | 写入 `tagmode=all` |
| 清空全部主题或快捷筛选 | 恢复任一 | 省略主题参数 |
