# 精选清单分享链接

「复制分享链接」按发送者清单顺序分享公开题录。接收者可以打开阅读面板和阅读模式，用「全部加入我的精选」将匹配到的文献追加到本机精选清单。接收者已有的条目保留原顺序，重复点击也只保留一份。

## 链接格式与上限

`?list=v1.<payload>` 中的 `payload` 是用换行连接的 ASCII 文献 ID，经 Base64URL 编码并去掉填充。发送端先在静态公开题录中匹配，再写入对应的站内 ID，包括 PubMed、RSS 和文献库现有 ID。接收端也接受裸 PMID 和裸 DOI 等别名。DOI 匹配不区分大小写，斜杠和百分号按原字符处理，接收端不再做一轮百分号解码。

单个 ID 最长 160 字符。每条链接最多 60 篇，生成的完整 URL 严格小于 2,000 字符。超过任一限制时，弹窗显示「复制前 N 篇的链接」，点击后复制可容纳的有序前缀。可以将其余文献另做一条清单链接。

生成的 URL 只带 `list` 参数。打开时 `list` 可与 `mode`、`day`、`tags`、`paper`、`theme` 等参数共存。阅读面板和阅读模式沿用站点历史逻辑。点击「关闭」只用 `replaceState` 从当前记录移除 `list`。

## 输入处理

| 输入 | 处理 |
| --- | --- |
| 重复的 `list` 参数、空值、未知版本、非 Base64URL 字符、无法解码的载荷或过长参数 | 忽略整个参数内容并显示一条提示 |
| 脚本标签、`javascript:`、外部 URL、空白、非 ASCII、控制字符或过长 ID | 忽略该条，保留同一链接中合法的 ID |
| 重复 ID、相同 PMID/DOI 的拼写别名、超过 60 篇的后续条目 | 按第一次出现的顺序处理，忽略重复或超限条目 |
| 格式合法但暂时无法匹配 | 等待文献库、信源和文献雷达延迟分片，必要时加载雷达存档 |
| 题录加载完成后仍无法匹配 | 在单个「N 篇在本站未找到」分组列出，展开后以纯文本显示原始 ID |
| 分片或存档加载失败且仍有未解析 ID | 提示暂无法确认，可刷新重试 |

## 隐私与范围

复制只对照站点已发布的静态题录，链接只包含公开文献 ID。清单快照里的题名、笔记和用户文本、浏览器申请记录及当前搜索参数都不参与编码。分享视图使用站点公开紧凑行，并沿用文献的常规阅读入口。分享功能无服务器存储、短链接服务或账号。
