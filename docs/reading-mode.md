# 阅读模式设计

阅读面板继续用于从列表打开文献并快速查看。头部的「展开阅读」进入适合连续阅读的全屏模式。复用 `#readerDrawer`、`#drawerBody`、现有 section 渲染、精选按钮和下载表单。现有功能地图和浏览器测试仍可通过原来的 ID 定位控件。

## 状态与历史

| 状态 | 进入 | 返回 |
| --- | --- | --- |
| 列表（closed） | 首屏或关闭阅读面板 | 使用正常栏目历史 |
| 阅读面板（drawer） | 从列表打开文献，压入一条面板历史 | 关闭或浏览器后退回列表，恢复列表触发元素的焦点 |
| 阅读模式（reading） | 从阅读面板展开，记录文献与滚动位置，再压入一条历史 | 返回、Esc 或浏览器后退恢复原面板、文献、滚动位置和「展开阅读」焦点 |
| 阅读模式（链接直达） | 确认文献后，在列表之上压入一条历史并打开 | 返回、Esc 或浏览器后退回列表，聚焦对应文献入口或列表导航 |

阅读模式独立读写 `paper=<paper.id>`，通过 `pushOverlay` / `popOverlay` 与面板协议衔接。切换篇目时替换当条历史中的 `paper`，保留筛选、其他查询参数和片段。后退逐层退出，前进可以恢复当前条目的阅读模式。链接直达先查题录索引，未命中时等现有题录分片及当前列表请求的雷达存档结束。空值、重复值、格式错误或最终未命中时清掉 `paper`，提示一次「没有找到这篇文献」。近 7 天榜的 `read` 仍由全文精读处理。

上一篇、下一篇和「第 n / 共 m 篇」都取 `getFilteredArticles()` 的当前结果顺序，覆盖全部当前筛选结果。首末篇各停在边界。分片到达或列表重绘后重算位置，当前文章移出结果时隐藏篇间切换，保留正文。切换到新篇从页首开始。

## 布局与交互

```text
桌面 1280+                     窄窗与手机
        返回  上一篇  篇数  下一篇  ☆     返回  上一篇  下一篇  ☆
        期刊信息、阅读进度                篇数、期刊信息、阅读进度
        正文单列（最多 760px）   目录    目录（按需展开）
        题名、摘要、研究结构             可滚动单列正文
        全文状态                         全文状态
        现有官网／分享操作               现有官网／分享操作 + 安全区
```

顶部与底部固定在中间正文滚动区之外。1280px 起目录在正文右边常驻，窄窗用「目录」展开或收起。目录只列已经渲染的小节，滚动时更新当前节和进度。系统要求减少动态效果时，目录跳转立即完成。打印把滚动区恢复为自然分页的单列，保留期刊、题名与正文，隐藏操作按钮和站点背景。沿用对话框的键盘循环与深浅色主题。

## 原型与生产实现

| 原型行为 | 生产实现 |
| --- | --- |
| 扫刊、选读、单篇连续阅读 | 现有列表 → 阅读面板 → 展开阅读 |
| 单列阅读、返回、Esc 焦点回位 | 复用阅读面板，增加浏览器历史、篇间切换、目录和进度 |
| 原型收藏 | 使用现有精选清单 |
| 已核开放 HTML 与公开 PDF 样例 | 按正式题录显示既有全文状态及官网入口 |
| 原型样式与内嵌样例 | 心知主题与正式题录；离线夹具只用于测试 |

全文精读日后可以复用排版、目录与进度的交互规则。两类页面各自保留内容来源、现有 URL 和历史协议。

## 内容边界

- 摘要按来源呈现。有公开摘要且站内未取得全文时用「仅摘要」，无可用摘要时用「暂无摘要」。只有 RSS 描述时标「RSS 短讯，非完整公开摘要」，保留取得公开摘要后的原文展示。
- 站内没有全文时显示「全文不可得」，保留现有任务进度、出处和操作。官网下载或网页全文的可用性取决于来源，口令入口仍按现有流程授权。
- 渲染沿用现有摘要、研究结构、速览和全文状态。阅读模式没有独立网络请求、全文嵌入和下载表单。速览标题为「速览」，「已核对导读」仍要求来源已核对。

## 验证

- 纯逻辑测试检查单篇、首末、未入筛选列表，以及合法、缺失、空、超长、脚本字符、重复的 `paper`。
- 离线浏览器在 1280×800 与 390×844 验证展开收起、连续阅读、异步分片、直达与坏链接、Back/Forward、Esc、Tab、目录、减少动态效果、打印、深色与 safe-area 布局。
- 对照原面板检查全文动作与口令表单的数量和节点，确保原抽屉、全文精读及已有权限路径保持原行为。跑整仓自验、功能地图与对比度检查，证据留在仓库之外。
