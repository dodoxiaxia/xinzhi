## 修改及数据契约

1. `scripts/source_fallbacks.py`：npj Health Systems 整刊查询；其他宽泛 Nature 期刊保留现有主题限制。保留先前 `09a71c49` 的修复意图并加强缓存证据处理。
2. `pubmedFallback.queryScope` 依据快照中的实际 `query`，取 `journal`、`cardiovascular_or_ai` 或 `unknown`。旧关键词查询保持原限制标记；缺少或无法识别查询时为 `unknown`，不能用今天的配置冒充旧快照覆盖。
3. `pubmedFallback.queryHash` 为原始快照查询的 SHA-256；无有效查询时为 null。输出不包含原查询正文。现有 provider、journal、checkedAt、stale、queryTruncated、实际条目计数继续保留。
4. `scripts/refresh_feeds.py`：非订阅 HTML 中实际引用的 `verify.nature.com` 验证资源，以及 canonical/form 目标的 Cookie 错误，可用于明确失败原因。文字提及、注释、普通参考链接及相似域名不构成该证据。只是 HTML 根节点时仍保留通用原因，不能凭旧页面样本补造本轮子类型。
5. HTTP 拒绝响应保留最终地址（脱敏）和 Content-Type，不读取拒绝页面正文、不重试。原有同主机拒绝/验证后的停止机制及缓存 sourceId/sourceUrl/fetchedAt 保留。

最新快照的 6 个失败来源为 Nature Medicine、Nature Reviews Psychology、Nature Communications、NPJ Digital Medicine、npj Health Systems、Cardiovascular Diabetology。原始结果均为 HTTP 200 HTML，具体页面子类型未保留。离线构建继续保留其 `not_feed` 状态和原缓存时间。

## 交付边界与剩余问题

此候选尚未集成发布。新整刊查询将在原任务审核集成后的既有题录刷新中生效；现有旧快照不会凭代码变更自动多出文章。PubMed 仍有收录延迟和全局结果上限，整刊查询不等于完整覆盖。

本环境核对生产 `public.js` 时一次请求返回 HTTP 403，已停止该主机访问；这是本环境的读验证阻塞，不能据此断言所有用户都无法访问。验证改用可访问的固定 state 和离线样本。没有调用模型，没有新建任务或扩大权限。

推送前核对两个现有 workflow：push 均只匹配 main，生产 job 同样要求 main。本补丁只交付新的隔离分支；不改 main/state、不手动触发 Actions，由原任务 `01a11479` 保留唯一集成发布权。
