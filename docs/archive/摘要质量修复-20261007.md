## 最小改动及门禁

- `editorial/public_abstract_evidence.json` 保存两例的公开字段证据、来源地址、响应哈希、原摘要及整段摘要哈希。只有 DOI、规范化题名和整段原文本哈希都匹配才应用旧数据修正；同 DOI 后续出现新的真实摘要时不会被旧修正覆盖。
- `scripts/abstract_quality.py` 保留 JATS/HTML 明确标记的段落和小标题，分离实际 funding-group 等元数据容器。普通正文中的基金名、编号、FundRef DOI 和统计数字不作关键词删除；真正摘要中的 Funding 小节保留。
- RSS 读取保留原描述里的结构标签，避免原生 XML 子节点提前被 itertext 粘合；可读摘要数量不再把本例资助串计作摘要。
- `auto_picks` 和 `week_precompute.public_abstract` 增加摘要质量门禁；公开构建同时移除固定 state 中本例旧的每日精选标记，避免等到下轮刷新才生效。
- 公开构建保留题录和独立的资助元数据；本例不会被未核实的旧缓存重新补成摘要。新增代码及证据文件纳入既有构建输入哈希。

固定 state 的 868 个候选中，摘要修正恰好影响上述 2 条。EHJ 原来已入每日精选；修复后该条评分为 0，公开 autoPick 去除。JAHA 保留可读摘要和原精选标记。已有 12 篇人工导读的公开内容完全保持。
