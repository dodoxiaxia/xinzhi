# v14.2.16：公开摘要 API 期限与任务状态

本版在生产 v14.2.15（afe3ca1447beb12fb2441a101f816a781aa1ae2a）上合版，使用已保存运行状态 efaaf69713fcc8b5468b9d0052daa672a666df0e。只发布原有六文件站点与 Worker；公开网站和私有全文归档边界继续独立。

## 读者可见变化

摘要翻译、标题翻译、AI 速览、研究结构、逐篇对照及讨论提纲在等待 45 秒时提示耗时较长。浏览器付费请求最多等待 170 秒，读缓存最多等待 15 秒（包含正文）。网络中断、响应正文中断和无法确认完成的任务进入等待确认状态，提供只读“读取已有结果”按钮；不会自动再次 POST。读取回执明确失败或任务已结束后，读者才可点击重新生成。迟到响应不能覆盖较新的请求记录。

Worker 公开元数据请求 8 秒内完成正文读取，最多 1 MiB。取源批次 35 秒、并发 2；包括最多 8 篇的讨论提纲。生成任务工作期限 150 秒，模型单次期限仍为 45 秒，每任务最多两次模型尝试。退款、终态记录和释放锁各自最多等待 2 秒，清理为 best effort。

新任务采用 owner UUID 与 deadline 的 180 秒租约，只有观察到自己仍为 owner 的任务才可保存结果、终态和释放锁。GET 仅返回安全的 idle/waiting/completed/failed 状态及重查提示，不调用模型、不修改锁。兼容旧值 `1`，不批量清理已有缓存/锁。KV 最终一致、非原子 CAS；不得把此机制描述为全局互斥或零重复计费保证。

发布构建将本周已验证公开摘要及与当前来源匹配的已批准目录投影为有限快照（最多 96 个身份），嵌入现有 Worker。精确匹配 PMID/DOI、核对标题与完整摘要 SHA256 后使用；来源只允许核准公开元数据主机的 HTTPS URL。无需新 ASSETS 路由、绑定或权限。历史未覆盖条目仍取严格匹配的远端来源；没有声称所有历史文献都可调用。完整引句、数字校验和 GLM 开关继续保留。

## 验证和限制

新增后端离线回归覆盖正文停顿、批次/总期限、取消、旧任务与新 owner、只读失败回执、额度与尝试次数、旧锁以及无效快照；新增实际 app helper 回归覆盖 12 个等待/恢复场景；公开快照构建 8 项回归。既有 study timeout 测试按新明确语义更新为 504/metadata_timeout。

完整测试、实际生产状态构建、四种桌面/手机 cards/compact 浏览器场景和三 ZIP 字节核验结果由最终发布回执记录。浏览器 API 是本地拦截的模拟服务，无真实模型消费；不得表述为真实生产 API 压测或用户原事故复现。独立后端 Agent 已只读复核前端合同，发现的 brief 正文错误及无期限启动探测均已修复。

旧报告的 225.7 秒超时和长期 409 缺少原始请求/生产日志。本版修复有离线证据的流程缺口，未断定它们就是原事故根因。最新 .15 独立 QA 未复现的 M7/M3/H4 不再重复修复；M10 布局改进及性能拆包、后续题录包另版验收，避免扩大本版范围。

## 运维动作

沿用现有每日完整刷新及两小时轻刷，没有新建定时器。每次发布核对 GitHub Actions 抓取/构建、Cloudflare 部署回执、state 保存和六文件 SHA256；摘要待预生成队列与实际 coverage 必须一致。读取 taskStatus=waiting 时先 GET；超过租约仍无结果则核对终态回执，不靠刷新页面反复 POST。metadata_timeout/error 与 no_abstract 分开记录，不把暂时取源失败解释为论文没有摘要。

Cloudflare 已出现的安全拦截和权限不足保持停止状态，没有升级 token、关闭策略或换域绕过。生产模型及真机体验仍需真实请求证据；本版不修改私有文献库、不下载 PDF、不触发新的全文任务。
