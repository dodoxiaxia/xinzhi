# 产品方案与 AGY 审阅结论

2026-09-29。用户选择：每日精选＋每周重点精读，兼顾 AI 医疗与心血管；公开摘要与原文链接，内部保留共读记录。

## 内容组织

- 每日 3–5 篇是目标阅读量，而非必须填满的配额。先从相关性、临床问题与方法学学习价值筛选，核对源文后再给出中文导读。
- 每周 1 篇主文献，必要时补 1–2 篇对照资料。允许经典研究；不把旧文标成今日新研究。
- AI医疗、心血管、交叉研究作为三个并列入口。首期重点可从 AI-ECG、房颤、心衰、影像与人机协作选择。
- 研究设计、偏倚、外部验证、患者终点、适用范围分开呈现。没有一个自动分数可替代这些维度。

每条正式导读应含：中文题名、原题名、期刊、DOI/来源链接、在线/卷期日期依据、阅读依据（索引/摘要/全文）、研究问题与类型、已核对结果、限制、适用范围、编辑状态。未提供的信息保留空缺，不从题名补出结果。

## 采用 AIHOT 哪些思路

参考仓库提供采集、初筛、独立两次评分、摘要、聚簇、日报与后台。热榜源码使用 48 小时窗口、24 小时半衰期与至少两个独立来源门槛。因此热度可以表达传播关注度，但不能解释为临床证据等级。单源文献不应因此被排除出精选。

原仓库还提供采集调度、模型调用预算回执、统一发布读取层，可作为后续持久化服务的基底。静态源码设计存在，不代表这些机制已在本站实测。原框架性能数字也不是本站的测试成绩。

未采纳或修正：

- 不采用“临床权重 = RCT 固定分 + 期刊背书 + 样本量”的公式；未验证的分数会掩盖研究问题与偏倚。
- 不采用报告中不一致的 E0–E5 编号，也不把所有研究硬塞到一个等级序列。

- “298 双阳性”只是原索引关键词信号筛选，不是内容已验证的篇数。
- 不把报告中的“毫秒级页面性能”“回执必然防重复扣费”当成此站已验证的生产保证。
- 不采用按职称强制审核的规定；编辑负责人由科室确定，记录实际核对范围即可。
