# DOI 官网页面 PDF 来源修复（v14.2.20）

输入 `10.1093/eurheartj/ehag734` 后，原流程把 Crossref 当前题名与 Unpaywall/OpenAlex 的旧题名逐字比较。当前题名包含 “silent cerebral embolic lesions”，后二者仍写 “silent cerebral embolism”；DOI 和官网 PDF 链接相同，却返回“全文来源关联需要核验”，未尝试取得文件。

获取全文仍先复用已经核验的 GitHub 原文。没有库内文件时，新流程使用同一次、相同 DOI 的 Crossref 响应中明确声明为 `application/pdf` 的链接，再保留原有开放获取来源作为后备。链接只存在于请求上下文，不进入题录、KV 或公开响应。最多三个去重链接，沿用既有可信域名、重定向、超时及大小限制；新增来源须达到 50 KiB 并通过 PDF 文件校验。

既有题名/哈希冲突、人工归档、密码、暂停与只读检查守卫保持有效。题名核验状态可以通过一次获授权的下载提交恢复；成功后同一响应返回附件并保存已核验缓存。来源拒绝、登录页面或限流仍停止请求，不能以题录存在代替全文成功。

回归使用合成文件和本地请求，覆盖上述 DOI 的旧题名、已保存核验状态、单次提交下载、缓存复用及来源拒绝；新测试加入既有发布门槛。真实公开元数据已核对，但本环境浏览器访问该官网 PDF 返回 HTTP 403，没有取得真实文件。因此离线下载测试通过不代表该论文的线上文件下载已经验收。
