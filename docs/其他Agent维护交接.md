# 维护交接（v13.5.1）

先读 [运营说明](自动化发布说明.md)、[当前交付状态](当前交付状态.md)，再读 main 代码和固定 state 结果。不要用历史 08:00 本机计划、v7 手动上传或“无 remote”推断当前运行。

用户要求 dot 统筹 GPT/Codex，普通工作约 5 分钟给反馈；已授权必要步骤自动继续。本轮授权网站修复和新版发布。权限以会话实际指令为准，本交接不授予任意未来部署。

main 是代码/人工稿，state 是私有抓取与最近成功公开构建。唯一发布入口 daily.yml：快刷两小时、完整刷新每天 05:17 北京；相关源码 push 轻量查新与发布。失败保留有效生产/state，最终 artifact 记录真实结果。外部旧 fast dispatch 默认忽略；无账户证据不能称 Cron 已停。

公开只有六文件（含 _worker.js），数据经 build_public 白名单。不得公开 PDF、.local、凭据、私人笔记或原私人索引；AI- 入库和网站发布分开。Macmini 是归档目标，不是默认计算端。

区分自动题录、原摘要、未核验 AI 速览、摘要核对导读、全文精读。既有 12 篇导读的正文和日期保留；source_checked 不等于全文审查，published=false 不公开。缺导读元数据、丢历史或缺摘要缓存就停止，不能删缓存“解决”。取得全文并审查前，本周未发布，不改旧期日期。

模型只处理公开题名/摘要，严格 quote/数字/长度校验；逐项失败跳过，provider 故障停止，合法输出原子合并，旧缓存保留。诊断只存安全 stage/code/type/status，不存响应或 key。不得读取秘密环境变量或密钥文件排查配置。

验证相关 Python 单测、node 阅读语义测试、受影响离线 fixtures；完整 state 上构建恰好六文件并核对 counts。Pages 接受和公网验收分开；网络阻断不等于站点故障。接手依据为 run/code SHA、artifact 与 state metadata，不重复生产部署来“核对一下”。
