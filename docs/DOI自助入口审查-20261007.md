## 当前授权与实际行为

用户于北京时间 **2026-10-07 18:10:48** 明确允许网站「先取已有全文或合法开放全文；需要订阅的再转授权下载流程」。本次恢复并加强现有 OA 获取，**取代早期 b909032/f5f3839 中停止 OA 的方案**；集成必须使用最终提交，不能只合旧补丁。dot 直接指定 DOI 与定期查新的来源规则不受这个网站授权变更影响。

现有 `/api/acquire` 完成同源与口令校验、DOI 规范化、Crossref 身份解析、固定 GitHub 索引/原件复用；未命中再查 Unpaywall/OpenAlex 明确标记的 OA 来源。来源必须 DOI/题名一致、HTTPS/主机白名单、受限重定向及体积，PDF 检查头/EOF/≥50 KiB/大小/SHA；GitHub 原件另验证 Git blob。没有第二入口或消费者。

- 已有 GitHub 原件或缓存命中立即复用；重复提交不新增源请求、KV PDF 或题录。
- 合法 OA 成功是 `oa_cached`；无 OA 是 `manual_needed`，明确等待授权订阅桥，不假设云端能控制 Mac Safari。
- 元数据或 OA 来源 401/403/429 暂停，PDF 返回 HTML 等非 PDF 内容也暂停，不能继续换源循环；`blocked`/`review`/`manual_needed` 重复提交只查状态。
- 可恢复的来源临时故障是 `retry_wait`，保留已核题录与真实五分钟重试期限；busy、日额度、KV 同步仍保留 main 的 Retry-After/北京时间提示，无自动重试。
- GitHub 索引读取失败不能落入新 OA 下载，避免查重未完成仍获取。DOI 拒绝路径穿越片段和二次编码残留。
- 保护结果增加 `archive.scope=website_cache`，`complete=false`、`executionClaimed=false`、`ledgerChecked=false`；三端 pending。缓存可下载不代表严格双解析器全文身份或三端归档完成。

网站现有 KV 软锁/额度只是尽力防重，不是严格跨区域互斥；目前入口未接 815 ledger、Drive/Mac 写入。不可将这部分交付宣称为新文献自动三端入库。`/api/pdf` 与只读 GitHub 凭据不改，不借用其写权限。

暂停恢复是维护者在确认原因解决后对精确 DOI 的既有 attempt/record 做受控操作；单纯等待不解除 blocked/review/manual-needed。此补丁不添加公开解锁接口。

## 唯一云执行器接入包

见 [`proposals/doi-cloud-bridge/README.md`](../proposals/doi-cloud-bridge/README.md)：选择现有 Pages + 一个私有 R2 + 一个 Actions executor；在同一领取账本中保存持久提交/outbox和唯一 owner，不另建并行消费者。正式启用时同步 OA 获取必须从 Worker 迁到 executor，KV 仅作为缓存投影。

本次隔离原型已可离线运行：24 并发规范化同 DOI 只创建一次、跨实例只领取一次、不按过期时间抢占旧 owner、原子额度、200/204 dispatch 回执不当作执行完成；OIDC 固定 issuer/JWKS、RSA 签名、repo/ref/workflow SHA/run 验证；历史或离线 Mac 回执不能 complete。

原型没有接入活动路由；workflow 仅 `.example`，故意 fail closed。它不是完整归档上传器。审查包逐项列出 R2/新 dispatch token/AI- Contents 写凭据/Drive `drive.file` OAuth 接收方、提供方真实授权边界、Mac 离线行为及一次性验收步骤。原连接器可做监督读取，不能被宣称为网站运行时持久凭据。本次未创建任何资源/凭据/OAuth/调度，未切换账本 owner、停旧 Grok 或启动 consumer。
