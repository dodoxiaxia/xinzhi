仅准备本地公共书目候选。API、内容审核、远端 state 和唯一最终发布权仍归原网站任务。本补丁不读普通 PDF 正文、不下载 LFS 对象、不写文献源、不连接外发模型、不新增调度或权限配置。

结果为 7 组官方题录校正、1 组保留旧公共题录；**4 行 HOLD**（Lancet 两行、Science 一行、JAMA 一行）。`requiresPublicMetadataReview=true` 保留，提醒原任务处理这些身份缺口。HOLD 不是新增文章，也不证明两行是同一篇。

没有审核策略的新冲突同样不会由排序决定题录：存在旧公共记录则仅按白名单保留旧书目，并降为 HOLD；没有旧记录则不新增任一变体，审计记录 `hold_new_record`。DOI/PMID 身份矛盾、重复公开 ID 或旧题录无法匹配时停止，不静默删除。

## 字段与日期边界

精确公共白名单：`id,title,doi,pmid,url,journal,date,dateBasis,datePrecision,ingestedAt,metadataStatus,fulltextStatus,basis,localAvailable,category`。路径、PDF 指纹、账户、备注、整表、PDF 和自由文本来源均不进入公共 JSON/JS；不以文件名补题名。源订阅另有窄白名单并拒绝账户或凭据 URL。

仅有官方题录核验的 7 条 `metadataStatus=official_bibliography_checked`，仍全部 `fulltextStatus=not_verified`、`localAvailable=false`。其他条目为 `index_record_only` 或 HOLD。所有首次入库日期均 `ingestedAt=null`：不能用发表、Git 提交或生成时间代替。可靠来源不足时发表日期未知，刊期保留月精度，不伪造该月第一天。审核官方题录不代表读过、持有或获准分享全文。

候选不复制既有摘要、导读或私人笔记。原流程仍应沿用 `enrich_metadata.py` 的既有公开元数据丰富和独立导读归档，避免破坏网站分类及导读。构建投影只新增三个日期/状态字段，不修改 API、内容审核或界面权限。

## 复现与唯一集成入口

```sh
python3 scripts/sync_public_library.py \
  --source "$AUTHORIZED_SOURCE" \
  --source-commit fed03f8d789429fc84c94cefcb4b636d75ec9ee3 \
  --source-final \
  --previous-source-commit 7d1d0fac70a2c4e866068d941c4c34e85d7163f9 \
  --previous-library "$RESTORED_WEBSITE_LIBRARY"
python3 -m unittest discover -s scripts -p 'test_*.py'
```

CLI 仅写忽略目录 `.local/public-library-sync/library.json`、`library.js`、`audit.json`；第三项仅供维护者本地审查，不进入公共包。不能指定 public/data 输出。源读权限失败返回固定诊断码并停止，禁止绕过。相同输入跨进程重跑保留输出字节、生成时间和 mtime。

原任务集成顺序：恢复固定完整 state → 核对最终源和审核策略 → 运行本地同步 → 审查 HOLD 及标识纠正 → 批准两个 library 候选 → 沿用元数据丰富、六文件白名单构建和原发布门槛 → 原任务唯一发布入口。失败时保留旧公共快照。

源码允许交付到新隔离分支 `codex/public-library-sync-20261007`，供原任务正常 fetch/cherry-pick。推送前须确认远端仅有 `.github/workflows/daily.yml`，`push.branches=[main]` 且生产 job 限制 `github.ref == refs/heads/main`，无宽泛分支事件；分支如已存在先检查，不 force。不得推 main/state、合并、手动触发 Actions 或部署。该分支推送授权仅用于源码交付。

## 待确认的访问受众

建议匿名读者仅见公共题录、获准公开的摘要/导读及出版商链接。私有 PDF、私有索引检索、路径/LFS/缺失审计仅供明确获授权维护者，不公开整表或储存细节。

仍待明确：全文仅本人维护、指定医生共读，还是更广受众？若共读，需先确定具体账户和每篇全文共享授权，再由原任务设计受保护入口。本补丁不新增用户或权限，不搭建全文外发模型功能。
