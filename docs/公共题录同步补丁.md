## 字段与事实边界

源行只取题名、期刊、DOI、可选 PMID、发表日期和日期来源；路径和 SHA 仅参与内存中的私有存储核对或查重。不能用文件名补题名。私人备注、原始/当前路径、账户、文件哈希、PDF、整表和自由文本日期备注均不写入候选公共字段。

公共字段精确白名单为 `id`、`title`、`doi`、`pmid`、`url`、`journal`、`date`、`dateBasis`、`datePrecision`、`ingestedAt`、`metadataStatus`、`fulltextStatus`、`basis`、`localAvailable`、`category`。category 是既有题名/期刊规则分类，不是医学评价。DOI/PMID 只校验格式和一致性，不证明与全文身份一致。

日期来源转换为固定标签，不复制自由文本；不可靠、缺失或无可核验月份的日期为空，日期精度未知。刊期保留月精度，不能伪造为该月第一天。已知索引日期存在争议，所以所有日期标签明确为原索引记录、未经本次独立复核。

源 schema 没有可靠首次入库日期：全部 `ingestedAt=null`。不以发表日期、Git 提交日期或候选生成日期替代。全部 `metadataStatus=index_record_only`、`fulltextStatus=not_verified`、`localAvailable=false`；文件在 tree 中、LFS 指针存在、索引写“已核验”都不升级这些公开状态。

既有源订阅从原网站数据按独立字段白名单保留；拒绝账户 URL 和带凭据查询参数的 URL。公开构建只增加上述三个日期/状态字段的投影，不修改 API 或审稿逻辑。候选不复制既有稿件和摘要；集成时沿用原网站的元数据丰富及独立归档流程，避免破坏导读与分类。

## 可复现运行和原任务集成位置

使用现有获授权的源 checkout 及显式 40 位提交；源读取不请求网络或凭据，禁用 Git 按需取对象。无法读取提交、索引或 tree 时返回固定错误码并停止，不绕过访问限制。CLI 不接受输出到 public/data 的选项。

```sh
python3 scripts/sync_public_library.py \
  --source "$AUTHORIZED_SOURCE" \
  --source-commit "$FINAL_SOURCE_SHA" \
  --previous-library "$RESTORED_WEBSITE_LIBRARY"
python3 -m unittest discover -s scripts -p 'test_sync_public_library.py'
```

输出固定在忽略目录 `.local/public-library-sync/`：`library.json`、`library.js`、`audit.json`。最后一项只有本地核对元数据，不进入公开 bundle。源 CSV 不另行保存。原网站数据缺失时拒绝启动；既有题录无法匹配时拒绝静默删条；冲突 DOI/PMID、重复 ID 和可疑公开文本停止候选生成。相同输入跨进程重跑保留候选生成时间和文件 mtime，输出字节一致。

原任务集成顺序建议：固定并恢复完整网站 state → 确认上游最终 SHA → 同步并审核候选 audit（包括 DOI 修正和重复元数据）→ 将批准的两个 library 文件纳入原流程 → 沿用 `enrich_metadata.py` → 既有白名单构建、打包与发布门槛 → 原任务唯一发布入口。源读取/验证失败应保留原公开题录及明确其快照日期。代码本身没有接入 Actions、自动写 state 或部署功能，也没有创建第二个同步调度。

## 待确认的访问受众设计

建议匿名读者只访问公共题录、获准公开的摘要/导读和出版商链接；私有 PDF 的持有、缺失、LFS 状态和本地核对报告不面向匿名读者。

私有索引检索和单篇 PDF 只面向已明确获授权的维护者，沿用现有服务端登录及只读边界。当前指定账户不因本补丁自动扩大。若医生共读需要全文，应先确认具体受众和每篇全文的共享授权，再由原任务设计受保护入口。

仍待用户明确：全文只供本人维护、指定共读医生，还是更广受众？本补丁不新增权限配置，不向任何外部模型发送私人索引或全文，也不创建全文外发模型功能。
